# Convert Emoji to Text 😀➡️📝

This Python project converts emojis into meaningful text and also converts text back into emojis.

It also provides features to remove emojis and count emojis in a sentence.

---

## Features 🚀

* Convert emoji ➜ text
* Convert text ➜ emoji
* Remove emojis from sentence
* Count number of emojis

---

## Example 🧪

Input:
I love python ❤️🔥😂

Output:
I love python love awesome laugh
